# Chrome Web Store assets

- `screenshots/en/`: five English screenshots, 1280×800 PNG.
- `screenshots/zh_CN/`: five Simplified Chinese screenshots, 1280×800 PNG.
- `promo/small-promo-440x280.png`: required global promotional image.

All product captures use a disposable Chrome test profile and fictional sample bookmarks. They contain no personal bookmark or account data.
